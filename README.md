# Unidad 2 Práctica 4: Repositorio de librería Pygame

Repositorio con ejemplos prácticos de la librería Pygame y un minijuego original.

## ¿Qué es Pygame?
Pygame es la librería de Python para crear videojuegos 2D. Permite manejar ventanas, dibujar, mover personajes, detectar colisiones, poner música y controles de teclado/joystick.
